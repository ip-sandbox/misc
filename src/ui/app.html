Zernike PSF Viewer

Zernike 係数（Noll インデックス、Noll 正規化、位相は rad）から瞳関数 P = A·exp(iW) を作り、PSF = |FFT2(P)|²（総和正規化）を表示します。 規約は torchmfbd/zern.py に準拠しています。

キー動作
Ctrl+N全係数をクリア
Ctrl+O / Ctrl+S設定の読込 / 保存
Ctrl+EPNG エクスポート
Ctrl+Z / Ctrl+Y元に戻す / やり直し
Ctrl+F係数の絞り込み欄にフォーカス
↑ / ↓選択中の係数を ±0.05 rad
Shift+↑ / ↓±0.005 rad
PageUp / PageDown±0.5 rad
LPSF をリニア ⇔ 対数
R表示レンジを自動調整
ホイールPSF のズーム
F1このヘルプ

注意: 中心遮蔽・スパイダー・矩形瞳では Zernike の直交性が崩れるため、 RMS は係数の二乗和ではなくマップから数値的に計算しています。
計算は Web Worker で行い、起動しない環境では自動的にメインスレッドへ切り替えます （画面右下に表示）。URL の末尾に ?backend=main を付けると固定できます。
